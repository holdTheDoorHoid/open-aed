# Letter 3: defibrillator manufacturers

**To:** medical or clinical affairs
**Subject:** Research enquiry: de-identified device recordings for open rhythm-analysis validation

*Expect a refusal or no reply. This letter is worth sending mainly to learn whether any route exists.*

---

Dear Sir or Madam,

I lead a small open source project designing a belt-worn defibrillator for trained responders, publishing designs, firmware and test results. It is at the simulation stage. It is not a medical device, is not a commercial product, and has not been used on anyone. The project does not make or sell devices.

Our rhythm-analysis software has been scored on public databases and falls short of the American Heart Association targets for detecting ventricular fibrillation. Public data cannot take it further, because it contains no recordings from real out-of-hospital arrests.

I would like to ask whether your company has any programme under which researchers can:

1. request de-identified device recordings for algorithm validation, or
2. submit software for evaluation against your reference rhythm library, receiving only summary scores.

I am not affiliated with an institution. If your programme requires one, it would help to know that, so that I can approach a university partner.

A one-page summary is attached. The repository is at https://github.com/holdTheDoorHoid/open-aed.

Yours faithfully,
